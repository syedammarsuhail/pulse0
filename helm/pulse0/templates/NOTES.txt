HOSTED MODE: create your first organization with the platform admin token, then hand its admin key to the customer:
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "pulse0.fullname" . }} 4318:4318 &
   ADMIN=$(kubectl -n {{ .Release.Namespace }} get secret {{ .Values.hosted.adminTokenSecret }} -o jsonpath='{.data.{{ .Values.hosted.adminTokenKey }}}' | base64 -d)
   curl -s -X POST localhost:4318/admin/orgs -H "Authorization: Bearer $ADMIN" -H 'content-type: application/json' -d '{"name":"acme","daily_cap":5000000,"retention_hours":72}'
   The response contains the organization's admin key once (stored hashed afterwards). Customers sign in with it in the UI.
   Self-hosted data stays in your cluster; in hosted mode tenants' data lives on this volume, so back it up (see STORAGE-AND-COST.md).
{{- end }}
